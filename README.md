## 💻 Local Development & Build

### Prerequisites
- Node.js 18+ (tested on Node v20/v24)
- npm, pnpm, or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/AnushkaPotd4r/anushka-portfolio.git
cd anushka-portfolio

# Install dependencies
npm install
# or
pnpm install
```

### Run Locally
```bash
npm run dev
# Server will start on http://localhost:3000
```

### Production Build
```bash
npm run build
npm run start
```

## 🌐 Deployment on Vercel

1. Push your repository to GitHub:
   ```bash
   git add .
   git commit -m "Complete premium portfolio with photograph and resume"
   git push origin main
   ```
2. Navigate to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import your `anushka-portfolio` repository.
4. Framework Preset: **Next.js** (auto-detected).
5. Build Command: `npm run build` (configured to `next build --webpack`).
6. Click **Deploy**. Vercel will build and deploy the production website within 60 seconds with SSL and global CDN distribution.
